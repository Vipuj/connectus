2. The symbol

Built on a 64 × 64 grid. Two stroked pill-shaped links sit side by side, then the whole pair is rotated −45° about the centre (32, 32) and scaled to 92%. The links interlock: link 2 is drawn over link 1 at the lower crossing, and a short arc of link 1 is redrawn on top at the upper crossing. That redrawn arc is what makes it read as a chain. Never omit it.

React component (copy as is)

export function Logo({ variant = "light", size = 32, wordmark = true }) {
  const ink = "#251911", cream = "#fef9ef", orange = "#e64706";
  const a = variant === "dark" ? cream : ink;       // first link + wordmark
  return (
    <span style={{ display: "inline-flex", alignItems: "center", gap: size * 0.28 }}>
      <svg viewBox="0 0 64 64" width={size * 1.15} height={size * 1.15} fill="none" role="img" aria-label="Connectus">
        <g transform="translate(32 32) rotate(-45) scale(.92) translate(-32 -32)" strokeWidth="8">
          <rect x="8" y="19" width="30" height="26" rx="13" stroke={a} />
          <rect x="26" y="19" width="30" height="26" rx="13" stroke={orange} />
          <path d="M25 19A13 13 0 0 1 38 32" stroke={a} />
        </g>
      </svg>
      {wordmark && (
        <span style={{ font: `800 ${size}px/1 "Plus Jakarta Sans", system-ui, sans-serif`,
                       letterSpacing: "-0.05em", color: a }}>connectus</span>
      )}
    </span>
  );
}

If you need the wordmark as a standalone image, export it from the HTML lockup with the font loaded and convert the text to outlines, so it never depends on the font being installed.

7. Do and don’t

Do

  • Use the SVG exactly as written above
  • Keep link 2 orange in every version
  • Use the cream first link on dark surfaces
  • Keep the interlock arc in every size
  • Keep the wordmark in a single colour, lowercase
  • Use the ink favicon tile for every icon size

Don’t

  • Redraw, trace or re-space the links
  • Round the favicon tile or add a shadow to the symbol
  • Add gradients, glows or outlines to the logo
  • Colour part of the wordmark or capitalise it
  • Stretch, rotate or recolour the links
  • Put rose or orange text on paper at body sizes

8. Checklist for the agent

  1. Load Plus Jakarta Sans at weights 300, 400, 600 and 800.
  2. Add the token block from section 6 to the app’s global styles.
  3. Create favicon.svg from section 4, export the PNG and ICO files, and add the head tags and manifest.
  4. Add the Logo component from section 3 to the header, sign-in screen and splash screen. Use the dark variant on ink surfaces.
  5. Check that the symbol matches section 2 at 16, 32 and 128 px, including the interlock arc.
  6. Check that nothing in the UI uses a blurred shadow, a radius or a gradient.
